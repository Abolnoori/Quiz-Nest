# 📚 Quiz-Nest

سامانه مدیریت کتاب و برگزاری آزمون آنلاین که با PHP و MySQL توسعه داده شده است.

## ✨ امکانات

- 🔐 ثبت‌نام و ورود کاربران
- 📚 مدیریت کتاب‌ها
- 🧩 مدیریت پودمان‌ها
- 📝 ایجاد و مدیریت آزمون
- ✅ ثبت و مدیریت پاسخ‌ها
- 🗄️ ذخیره اطلاعات در MySQL

## 🛠️ تکنولوژی‌ها

`PHP` `MySQL` `Bootstrap` `JavaScript` `HTML` `CSS`
