# 📚 Quiz-Nest

سامانه مدیریت کتاب و تست برای دانش‌آموزان کنکوری که با PHP و MySQL توسعه داده شده است.
برای مدیریت تست ها در زمان کنکور / امتحانات / و...

## ✨ امکانات

- 🔐 ثبت‌نام و ورود کاربران
- 📚 مدیریت کتاب‌ها
- 🧩 مدیریت پودمان‌ها
- 📝 ایجاد و مدیریت آزمون
- ✅ ثبت و مدیریت پاسخ‌ها
- 🗄️ ذخیره اطلاعات در MySQL

## 🛠️ تکنولوژی‌ها
